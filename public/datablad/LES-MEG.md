# Produktark og datablad

Legg PDF-ene her, og pek på dem fra `content/products.json`.

```json
"datasheets": [
  {
    "label": { "no": "Teknisk datablad", "en": "Technical data sheet" },
    "file": "/datablad/elektrisk-golfbil.pdf"
  }
]
```

Uten `file` viser produktsiden **«Be om produktark»** og sender kunden til
kontaktskjemaet med produktet ferdig utfylt. Legges filen inn, blir det samme
punktet til en nedlastingslenke.

Bruk gjerne filnavn som følger produktets adresse, for eksempel
`elektrisk-golfbil.pdf`, så er de lette å finne igjen senere.
